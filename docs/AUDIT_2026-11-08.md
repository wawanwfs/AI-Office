## Matriks pengembangan berikutnya

1. **Production baseline**: reproducible compose (Windows Docker Desktop/WSL2
   dan Linux), RBAC/auth, isolated ports, readiness probes, env validation,
   migrations, rollback dan backup yang diuji.
2. **Master orchestrator**: persistent queue, nonblocking task dispatch,
   multi-project parallelism, rate/concurrency limits, idempotent resume,
   per-agent logs, real retry/approval.
3. **Real full-stack preview**: per-project sandbox ports/domain routing,
   HTTPS proxy, WebSocket/SSE, preview logs, test output, artifact downloads,
   guaranteed cleanup.
4. **Office 3D + UI**: one design system across landing and application,
   floor/agent/project navigation, keyboard/touch parity, responsive layouts,
   performance budget, failover for non-WebGL devices.
5. **Observability + cost**: provider/model prices and usage, per project/agent
   allocation, budgets, alerts, traces and export.
6. **Quality gates**: unit, browser E2E, API contract, security scanner,
   dependency audit, image/container scan, chaos/fault recovery, accessibility.

**Kriteria kelulusan production**: bukan berdasarkan hitungan persentase
arbitrer; semua gate wajib hijau, deploy dan rollback teruji, serta tidak ada
temuan keamanan P0 terbuka.
